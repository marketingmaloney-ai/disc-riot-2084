# video02: full move set from Flow VIDEO (image-to-video), 4 clips per character
STATUS: READY

**How:** use Flow video with image-to-video, uploading the character's **start image** as the first frame. Choose **16:9 landscape**, paste the prompt exactly, and download the MP4. Save it as `tools/gen-assets/raw/<char>/vid_<clip>_v1.mp4`, or drop it in `tools/gen-assets/inbox/video02/` named like `vega_B.mp4`.

**Start images** (one clean pose on green, framed with room to move): `tools/gen-assets/video_starts/<char>_start.png`.
Don't start from a sprite strip or turnaround sheet with several figures. The video will morph and the first second is wasted.

Every prompt ends with the same **RULES** line. Keep it; it's what makes the clips usable as sprites.

RULES = `Locked-off static camera: no zoom, no pan, no shake, no cuts. The whole body stays fully inside the frame at the same size the entire time, seen from the side facing RIGHT.
