# video01: pilot, animations from Flow VIDEO (image-to-video)
STATUS: READY

A test of whether video clips make better sprites than image strips. **3 jobs, 1 video each.**

## How to generate (Flow → video)
1. Use Flow's **video** generation with the **start frame / image-to-video** option ("Frames to video" or "Ingredients"), and upload the job's `start:` image as the **first frame**.
2. **Aspect ratio: 16:9 LANDSCAPE.** Use the shortest duration offered.
3. Paste the prompt exactly, generate, and download the MP4 at the highest quality offered.
4. Save it to the job's output path as `_v1.mp4` (or drop it in `tools/gen-assets/inbox/video01/` named by job number, for example `V1.2.mp4`).
